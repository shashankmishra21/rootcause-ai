# RootCause AI 🔍

> AI-powered production incident analysis platform — automatically summarizes logs, detects severity, retrieves similar past incidents, and generates support tickets using RAG architecture.

## Tech Stack

**Backend:** Node.js · Express · TypeScript · Prisma · PostgreSQL · Redis  
**AI Service:** Python · FastAPI · sentence-transformers · Qdrant · Groq LLM  
**Frontend:** Next.js 14 · Tailwind CSS · ShadCN UI · Zustand · TanStack Query  
**Infra:** Docker · Docker Compose · Vercel · Render
